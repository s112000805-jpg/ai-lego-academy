## 🌟 專案簡介

**FLOW AI 學院 × AI樂高學堂** 是一個專為成人設計的 AI 階梯式學習平台，整合了 [@AI樂高學堂-p5j](https://www.youtube.com/@AI%E6%A8%82%E9%AB%98%E5%AD%B8%E5%A0%82-p5j) 頻道的優質教學影片。

使用者可以透過系統化的「四階學習地圖」進行積木式的逐步解鎖，並且具備 **AI 智能助教**、**即時實作筆記** 與 **進度備份** 功能，協助學習者無痛進入 AI 自動化與智能體 (AI Agent) 開發的世界。

---

## 🚀 核心功能特色

- 🎯 **四階學習地圖**：明確劃分基礎概念、Prompt 工程、自動化工具到 AI Agent 智能體應用。
- 📺 **內建影音播放與標籤篩選**：支援關鍵字搜尋、主題標籤 (Tag) 與多階段快速過濾。
- 🤖 **Gemini 3 Flash 智能助教**：內建 AI 對話助手，隨時解答影片內容、Anthropic 提示詞架構與 Vibe Coding 等實務問題。
- 📝 **個人化實作筆記**：每一單元均提供獨立筆記區，自動儲存至 LocalStorage，方便記錄 Prompt 靈感與程式碼。
- 📊 **遊戲化等級進度條**：依據解鎖單元數即時提升稱號（從 `LV.1 積木新手` 到 `LV.MAX AI 大師`）。
- 💾 **完整 JSON 數據備份**：支援單鍵匯出與匯入個人學習進度與筆記，隨時跨裝置轉移。
- 🌓 **深色 / 淺色模式（Dark Mode）**：適應各種閱讀情境與個人視覺偏好。

## 💻 快速開始 (Quick Start)

### 本地開啟
由於本專案為單一可執行檔架構，無需安裝 Node.js 或繁雜的構建流程：

1. 下載或複製本專案的 `index.html` 檔案。
2. 直接點擊 `index.html` 即可在瀏覽器（Chrome / Edge / Firefox / Safari）中開啓使用。

---

## 🌐 部署至 GitHub Pages

若您希望將此平台託管上線並分享給朋友：

1. 在 GitHub 上建立一個新的公開儲存庫（例如 `ai-lego-academy`）。
2. 將 `index.html` 上傳至儲存庫根目錄。
3. 前往專案 **Settings > Pages**。
4. 在 **Build and deployment > Branch** 選項中，將 `None` 切換為 `main` 並點擊 **Save**。
5. 等待 1~2 分鐘後，即可取得免費且自動更新的專屬網站網址！
